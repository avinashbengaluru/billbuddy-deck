## 🌟 Featured Projects

### 1. ⚡ BillBuddy — ERP Operational Platform & Interactive Presentation
> **Live Presentation Deck:** [https://avinashbengaluru.github.io/billbuddy-deck/mobile.html](https://avinashbengaluru.github.io/billbuddy-deck/mobile.html)  
> **Repository:** [`avinashbengaluru/billbuddy-deck`](https://github.com/avinashbengaluru/billbuddy-deck)

A specialized operational web platform designed to eliminate clerk friction in multi-item distribution while keeping **Tally Prime** as an immutable general ledger.

* **1-Tap WhatsApp Quotations & Payment:** Generates branded PDF quotes with embedded PhonePe UPI links in ~10 seconds, auto-delivering via WhatsApp API.
* **Zero Tally Re-Typing:** Automatically posts Customer Ledgers, Sales Vouchers, and Payment Receipts into Tally Prime in 1 unified API call upon payment.
* **Resilient Offline Architecture:** Postgres SQL DB queuing that buffers transactions locally if Tally is offline, auto-syncing upon reconnection.
* **Interactive Animated Presentation:** Built an 10-slide interactive SVG presentation deck showcasing live system pipelines, process justifications, and operational metrics.
